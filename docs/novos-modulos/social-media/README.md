# Modulo de Midias Sociais

## Objetivo de marketing

Usar canais sociais como motor de aquecimento para PDEs: educar a dor, mostrar o
mecanismo de IA de forma invisivel, gerar prova e preparar o publico para compra.

## Primeiro canal: YouTube

O YouTube deve ser tratado como ativo de longo prazo:

- videos longos para educacao e prova;
- Shorts para alcance e descoberta;
- playlists por promessa, dor ou caso de uso;
- comentarios como fonte de objecoes e linguagem real do mercado;
- links rastreaveis para pagina, lista ou checkout quando o experimento estiver pronto.

## Pauta inicial recomendada

1. Dor cotidiana: mostrar o custo de continuar fazendo do jeito dificil.
2. Mecanismo PDE: demonstrar a IA aplicada sem explicar tecnicamente a IA.
3. Prova rapida: antes/depois, demo ou caso de uso claro.
4. Objeções: responder medo, tempo, dificuldade e confianca.
5. CTA: levar para lista, diagnostico, pagina de venda ou oferta de entrada.

## Implementacao

O modulo criado e o `social-media-worker`. Ele comeca pelo YouTube e deve crescer
por canais independentes, sem acoplar Instagram, TikTok ou outras redes na etapa
concreta do YouTube.
