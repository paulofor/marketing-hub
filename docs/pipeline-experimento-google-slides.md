# Apresentação Google — Pipeline de Experimento

Este documento acompanha a apresentação `docs/pipeline-experimento-google-slides.pptx`, pronta para upload e edição no Google Apresentações.

## Como abrir no Google Apresentações

1. Acesse o Google Drive.
2. Clique em **Novo** → **Upload de arquivo**.
3. Selecione `docs/pipeline-experimento-google-slides.pptx`.
4. Após o upload, abra o arquivo com **Google Apresentações**.

## Estrutura dos slides

1. Objetivo do pipeline
2. Entrada do experimento
3. Produção de artefatos
4. Publicação e ativação
5. Coleta e monitoramento
6. Aprendizado automatizado
7. Governança e próximos passos

## Observação

O arquivo está em `.pptx` para compatibilidade com edição colaborativa no Google Apresentações.
