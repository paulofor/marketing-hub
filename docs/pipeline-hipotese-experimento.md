# Apresentação — Pipeline de Hipótese para Experimento

Este diretório mantém a apresentação em `docs/pipeline-hipotese-experimento.pptx` para edição no Google Apresentações.

## Armazenamento de binários no GitHub

- O repositório está configurado para versionar arquivos `.pptx` usando Git LFS.
- Regra aplicada em `.gitattributes`: `*.pptx filter=lfs diff=lfs merge=lfs -text`.
- Isso permite armazenar binários com histórico mais estável para merge/review.

## Como usar no Google Apresentações

1. Abra o Google Drive.
2. Clique em **Novo** → **Upload de arquivo**.
3. Selecione `docs/pipeline-hipotese-experimento.pptx`.
4. Após upload, abra com Google Apresentações para editar e compartilhar.

## Estrutura dos slides

1. **Da Hipótese à Campanha no Ar**
   - Visão geral do pipeline em duas camadas: hipótese e experimento.
2. **Pipeline no nível da hipótese**
   - Framework: dor, resultado, mecanismo, prova e oferta.
3. **Pipeline no nível de experimento**
   - Geração de: ângulo de campanha, texto de anúncio, briefing de imagem, texto e layout da landing.
4. **Produção final, publicação e aprendizado**
   - Criação dos anúncios, publicação da landing e início da otimização.
