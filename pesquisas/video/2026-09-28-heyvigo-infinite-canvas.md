# Radar de IA para vídeo — 2026-09-28

Uma mudança passou o filtro: a HeyVigo lançou o Infinite Canvas, ativo no aplicativo web. Ele organiza texto, imagem, vídeo e áudio como nós conectados, preserva relações entre fonte, decisões e outputs, permite ramificações e mantém confirmação humana para mudanças propostas pela IA.

Para o Marketing Hub, a implicação é manter um `production_graph` versionado: briefing -> referência -> storyboard -> tomada -> render -> revisão -> versão aprovada. Novas tentativas devem criar branches sem sobrescrever assets aprovados.

Status: ativo no web; não foi localizada API pública específica do Canvas. Planos públicos: Lite US$19/mês, Pro US$59/mês, Ultra US$199/mês. Uso comercial depende do plano, dos direitos de terceiros e dos termos do modelo escolhido.
