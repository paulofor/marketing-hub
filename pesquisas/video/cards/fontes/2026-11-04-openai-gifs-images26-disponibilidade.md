# Reviewed evidence - OpenAI native animated GIFs in ChatGPT (2026-11-04)

## New event and source date
- The Verge (Emma Roth), published November 4, 2026 at 18:00 UTC / 15:00 in Sao Paulo, reports that animated GIF generation is rolling out in ChatGPT with Images 2.6.
- Reported capabilities: make GIFs from a text prompt or uploaded photo, adjust playback speed, inspect and edit individual frames, then share.
- The article attributes an example of a dancing cat GIF to OpenAI. This is a native short-form animated image workflow, not proof of a general text-to-video model, audio generation, lip-sync, long takes, or cinematic camera control.

## Availability: important evidence limits
- Status: REPORTED ROLLOUT, LIMITED BY ACCOUNT and platform. The article says rollout to ChatGPT and Codex web, desktop and mobile; no authenticated user-account test was made.
- As checked at this run, OpenAI's public news index, API image generation guide and API changelog had not yet published documentation for Images 2.6/GIF output. This is one credible contemporaneous media report, not an independent endpoint verification.
- The Verge also reports new GPT-Image-2.6 Flare and Sunburst API offerings for image generation, but this does not demonstrate public GIF OUTPUT support in the Images API.
- Neither public prices for 2.6 nor animated GIF duration, frame rate, frame-count ceiling, resolution, quotas or supported commercial export terms were confirmed. Do not invent specifications.
- No open weights were announced. Treat as proprietary and review current rights to images, logos, audio and likeness used as inputs.

## Competitors and lifecycle checked November 4
- Kling 4.0 (China) is ACTIVE via Runway Dev API, including 3-30-second 720p/1080p video with audio, editing and references. A silent GIF is not a quality-equivalent alternative.
- Google Veo 3.1 GA (United States) remains ACTIVE on Gemini Enterprise Agent Platform / Google Cloud. Official documentation currently lists its retirement date as November 17, 2026 OR LATER, so that is an earliest date, not a guaranteed shutdown date; check before long-term integrations. Veo 3.1 Preview Gemini API endpoints shut down October 22, 2026.
- Google Genie 4 (United States) is LIMITED to research testers as of the October 27 announcement; not a public production service.
- Synthesia plugin for ChatGPT (UK) is ACTIVE per the November 3 vendor launch, while underlying MCP is in PUBLIC BETA; it makes explainers and avatar videos, not GIFs.
- OpenAI Sora app/web stopped April 26, 2026 and Sora API stopped September 24, 2026; GIF availability is a different product, not a relaunch.

## Marketing Hub application
- Candidate experiment: convert one authorized product still and a two-line CTA into a short loop, test frame-level revisions and playback rate, and compare with MP4/WebM versions.
- Measure visual consistency, readability, mobile size/load, accessibility preferences, placement compliance, approvals, and cost per accepted conversion asset.
- Do not depend on an unverified GIF API or infer that all paid/free accounts already have the feature.
