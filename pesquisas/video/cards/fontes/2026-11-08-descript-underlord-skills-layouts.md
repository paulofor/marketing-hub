# Descript — Underlord Skills e pacotes visuais de marca

**Data do changelog oficial:** 06/11/2026. **Verificação:** 08/11/2026.

## Fonte primária

- Descript, *Release roundup—November 6, 2026*: https://feedback.descript.com/changelog/release-roundupnovember-6-2026

O changelog reúne funcionalidades lançadas ao longo de outubro/começo de novembro; portanto **06/11 é a data da compilação oficial, não necessariamente o dia em que cada recurso foi habilitado**.

## O que ficou disponível

1. **Underlord Skills:** permite salvar instruções/edições bem-sucedidas como procedimentos reutilizáveis e acioná-los com o comando de barra / no chat do Underlord. É possível combinar skills e editar instruções. **Status: ATIVO no editor Descript**, sem comprovação de API pública específica para criar skills.
2. **AI Brand Layout Packs:** carregar manual de marca, logotipo e cores, ou descrever estilo, para gerar quatro direções e um pacote de layouts editáveis usado por projetos da mesma equipe; Underlord pode ajustar layouts e cenas. **Status: ATIVO nos planos pagos**, consumindo créditos de IA. O changelog não fornece preço exato por pacote.
3. **Busca semântica visual:** pesquisar cenas pelo conteúdo visual (por exemplo, um quadro branco), inclusive via Descript MCP e API. **Status: ATIVO apenas nos drives Enterprise** segundo anúncio oficial.
4. **Integração ChatGPT:** uploader envia arquivos para projeto do Descript, onde Underlord pode editá-los. **Status: recurso anunciado/ativo no fluxo documentado**, dependente das contas e integrações habilitadas.

**Descontinuação anunciada:** templates antigos de prompts do Underlord deixam de funcionar em **30/11/2026**; templates pessoais precisam ser salvos como skills pelo usuário e não são convertidos automaticamente. Isso é um evento de migração real, não o encerramento do Descript.

## Comparação e cautelas

Descript não é concorrente direto de modelos de renderização como Kling 4.0 Flash ou Gemini Omni 1.2: sua força é controlar montagem, reutilizar edição e manter marca. Comparar com Genspark Media Studio, Runway Workflows e Synthesia Studio como *orquestração*. Não afirmar que Underlord usa modelos abertos, que possui inferência local ou que cada skill pode ser acionada por API — esses pontos não foram confirmados.

## Experimento para Marketing Hub

Criar um brand pack para uma campanha e uma skill de edição reutilizável (corte, títulos, legendas, identidade visual), gerar dez variações de vídeos curtos a partir de ativos autorizados; medir minutos de revisão, consistência da marca, custo por vídeo aprovado, necessidade de correção manual e disponibilidade de fluxo externo. Atenção ao término dos templates em 30/11.
